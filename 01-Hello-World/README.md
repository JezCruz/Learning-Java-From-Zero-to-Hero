# Lesson 1 - Hello World

## Natutunan ko
- Ang `public` ay nagpapahintulot na ma-access ang class o method.
- Ang `class` ay blueprint ng object.
- Ang `main()` ang unang method na tumatakbo kapag ni-run ang program.
- Ang `print()` ay hindi lumilipat ng linya.
- Ang `println()` ay lumilipat sa susunod na linya.
