- What is Variable?

Variable is parang isang lalagyanan na pwede mo lagyan ng laman.

example: age = 23

so ang laman ng age ay 23.

- What is int?

int naman ito yung mag sasabi kung ano yung laman ng isang variable kung String or Whole number.

example: int age = 23;

so ang lalabas ay 23.

int age = 23;
System.out.print(age);

output: 23
